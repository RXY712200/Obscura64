# Support

Consult the [README](README.md) and [documentation index](docs/README.md) first
for supported behavior, integration, formats, recovery limits, and build notes.

- Reproducible bugs and technical problems: [GitHub Issues](https://github.com/RXY712200/Obscura64/issues).
  Include version, toolchain, Windows version, component, reproduction, and
  relevant results without secrets or private project data.
- Current project status and known validation gaps:
  [Issue #1 — Development Log, Known Issues & Roadmap](https://github.com/RXY712200/Obscura64/issues/1).
- Security-sensitive reports: follow [SECURITY.md](SECURITY.md).

This is a small open-source project. No SLA, guaranteed response time, or
commercial support is promised.
